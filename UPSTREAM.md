# uTLS maintenance

Baseline: official [refraction-networking/utls](https://github.com/refraction-networking/utls/tree/a13c59ffe98bb01b2ca14143eb2e887664b1f138),
commit `a13c59ffe98bb01b2ca14143eb2e887664b1f138`
(`v1.8.3-0.20261108164504-a13c59ffe98b`). Go 1.27+.

The fork supplies generic TLS mechanisms. Browser values and ECH policies live
in Surf. A nil `Config.ECHClientHelloInner` preserves upstream inner construction.
Servers retain upstream behavior.

## Changes to maintain

| Change | Owned files | Small upstream hooks |
| --- | --- | --- |
| Caller-supplied ECH inner cipher/extension layout, opaque extension preservation, contiguous outer references, raw RFC 9849 encoding | `u_ech_inner.go`, `u_ech_inner_test.go` | `Config` field and `Clone` in `common.go`; context fields in `handshake_client.go`; construction/encoding in `u_conn.go` |
| Rebuild custom inner after accepted-ECH HelloRetryRequest | same helper | two branches in `handshake_client_tls13.go`; copy the updated inner key share, retaining the private keys generated by the engine |
| Retain every generated client key share and select the matching private key | `u_key_share_test.go` | private map in `UConn`; population in `u_parrots.go`; selection in `establishHandshakeKeys`, excluding HRR-generated keys |
| Return ClientHello construction errors through the normal handshake cleanup | QUIC regression in `u_ech_inner_test.go` | `UConn.handshakeContext` records build errors rather than returning before QUIC channels close |
| Account for the new callback in Config clone audits | existing tests | two clone tests in `tls_test.go` |

Test-only formatting: the certificate generator applies `go/format` before
writing or comparing its fixture, so generated files satisfy the CI format check.

The raw encoder follows RFC 9849 section 6.1 and the upstream discussion in
[uTLS PR #432](https://github.com/refraction-networking/utls/pull/432).
The callback cannot replace key-share cryptography. Outer references must retain
outer order and form one contiguous run; ECH itself cannot be compressed.
The fork validates the private SNI, inner marker and TLS 1.3 versions/ciphers.

**Existing limitation retained:** real ECH with a populated custom PSK extension
is explicitly rejected. Custom ECH resumption and 0-RTT are not implemented by
this patch. GREASE ECH resumption and the stock Go TLS path remain separate.
Do not silently remove ECH, transmit private tickets in the outer hello, or
disable certificate verification to make this combination succeed.

## Updating

Keep the official Git history and the `upstream` remote. Start from a clean
checkout, fetch the desired official revision, and merge it in a separate
worktree. Resolve the hooks in the table above. Normalize only Go module/import
paths to `github.com/enetx/utls`; preserve upstream source links and licenses.
Update `upstream.json` after reviewing and testing the candidate.

```sh
GOWORK=off go mod tidy
GOWORK=off go test -race -count=1 ./...
GOWORK=off go vet ./...
GOWORK=off go test . -run '^$' -fuzz=FuzzCustomECHInnerRaw -fuzztime=10s
```

Also run Surf's full race/coverage suite against the candidate. Its ECH tests
exercise Chrome and Firefox over TCP and QUIC, native Chrome inner fixtures,
all initially offered key groups, HRR, verified certificates, policy errors and
application bodies. Firefox inner policy is source-derived; do not label it an
independently decrypted Firefox capture.
